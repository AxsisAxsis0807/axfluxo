動画・既存データは使いません。自動更新・keepaliveはありません。tokenはこのページのメモリー内だけに保持します。

DB観測開始後、別タブのdashboardでAPI partだけを停止してください。停止・再開の表示時刻を記録し、workerがRunningのままか確認します。アプリ全体を停止した場合は判定不能です。

API再開後、この画面でtokenを再入力して「観測結果を手動更新」を押します。eventsの時刻とdashboardで確認したAPI停止区間を照合してください。JSONだけでAPI停止を証明したとは扱いません。

手動停止は自動sleepの合格証拠ではありません。開始期限はDB保存され、再起動・再押下でも延長されません。
