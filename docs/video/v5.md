## 入口と制作フロー

`/developer/all-versions/`、`NEXT_PUBLIC_ALL_VERSIONS_ENABLED=true`で有効化。既定OFF。既存のSupabase sessionとdeveloper APIを使用し、素材→音声編集→名前→デザイン→全長preview→書き出し。素材画面にV2 library/uploadを組み込み、明示選択したverified version/hashだけを使用する。coverは画像、音源はMP3/WAV/M4A/MP4/MOV。MP4/MOVの映像は音源として扱い、最終映像にはcoverを使う。一般的なAAC M4A/MP3/PCM WAVを検証し、未対応codec/偽MIMEは既存の個別エラーで拒否する。既存画像上限やLibraryRef/backupの意味は変えない。

音声にもV3の全長proxy/thumbnail/多解像度波形を生成し、主時計はnative media element。V3 editorを再利用した中央head、scroll/zoom、前後trim、時刻/1frame操作、marker追加・数値移動・明示削除。clipの結合順を変更可能。trimでmarkerが区間外になる変更はエラーにし、marker/名前を削除して帳尻を合わせない。入力は非破壊で、元version/hashを常に固定する。

clip境界と内部markerがversion境界。境界を累積microsecondsから60fps整数frameへ丸める。ゼロframeのversion、空行、名前数、短すぎるfadeを検出して書き出しを止める。名前原文は改行/番号ごと保存し、任意の番号除去は別設定の表示・描画投影。自動的なtrim/空行削除/連番補完はしない。V5にversion数や動画時間の独自の固定上限は設けない。整数時刻の技術的範囲、HTTP body 1MiB（既存API共通）、実disk/RAM/quota/予算等は別の資源制約であり、超過はエラー/保留とする。V4の旧APIにあった100clip/100,000segment制限をV5入口へ適用しない。

## デザイン、font、preview

16:9、1920×1080または2560×1440、60fps MP4/H.264/libx264 CRF18 medium/yuv420p、AAC320k。正方形coverをcontainではなく正方形へcover cropし、同じ画像を拡大blurした背景へ重ねる。Aleoの白文字、黒stroke、半透明黒plate、1行自動縮小。stroke幅も縮小率に合わせる。音量・速度・音声fade・normalization/EQ等は追加しない。monoの互換変換はL/Rへのunity複製とし、既定のdownmix係数による約3dBの低下を避ける。AACはV4の全区間1回encodeを再利用し、映像segmentごとの音声encodeは行わない。

初期fadeは9frame in＋9frame out＝合計0.30秒。整数frameで変更可能。version区間に入らなければFADE_TOO_LONG。勝手にfade/marker/名前を短縮しない。fadeはglyph/strokeの文字PNGのalphaだけに適用し、cover、blur背景、黒plate、音声は固定する。

Aleoは同梱の未改変font、SHA-256 `62b6cb49b7b087b341f0307ea3bc871a9690d8947691206ab025d149b8f6ed6f`。rendererは`axfluxo-all-versions-v5.1`。project schemaのliteralで固定し、毎request/jobでfont実バイトhashを検証。cmapにない文字はFONT_GLYPH_UNSUPPORTED、欠損/改変はFONT_UNAVAILABLEとして止める。日本語等の未収録glyphを別fontへ黙って置換しない。Aleo以外のfallback font追加は今回の範囲外。

serverの同じrasterizerがpreview/workerへPNGを生成する。ブラウザー側のfont計測やHTML文字描画を正解にしない。previewはそのPNGを重ねて同じ整数frame alphaを使う。音源editor previewはV3のproxyをclipごとにseek/playするため、端末のclip切替までsample単位の無音なしを保証するものではない。「全長previewを生成」でV4 workerによる検証済みの全長MP4も再生でき、その結果をそのまま書き出しに共用する。signed URLの再取得時は再生位置を維持する。未生成の文字/素材previewは接続・認可が必要で、offline時に代替描画を捏造しない。

参考画像は未提供。実測位置・一致率は作っていない。`provisional-v1`: cover中心x=0.5、上端y=0.12、辺長=高さ0.56、文字中心y=0.855、plate x=0.05/y=0.78/w=0.90/h=0.15、文字利用幅0.86。これらは暫定の設計値で、reference検証未完了。editorのCSS blur縮小表示は端末差があり、最終正解はserver生成MP4。参考画像一致は判定しない。

V5の文字境界segmentはB-frame再並べ替えなしにし、1〜数frameの区間を結合した場合もCFR/container rateを維持。movie timescale=240000は60fpsと48kHzの両方を表せるため、短区間のMP4 edit listでaudio durationがms単位へ丸められることを防ぐ。旧V4の非template出力設定は変更しない。V4のlease/heartbeat/fencing/一意公開/原本保持/資源保留/checkpoint hash照合は維持する。template/font hashをrender artifactの検証記録にも残す。

## 保存と同期

独立AllVersionsProject v1を`axfluxo-developer` **v1の既存storeだけ**へ保存。旧AllVersionsDocument v1を変更せずproject.documentに含める。documentsの`av5:owner:project` keyでローカルrevision CAS。750ms debounce＋直列Promise queue。手動保存はflush barrier。documentと同期outbox（snapshots store）を一つのIDB readwrite transactionで確定する。保存失敗時は未保存のまま、編集と再試行対象を保持する。

local CAS競合時は勝者を更新せず、敗者のproposalもsnapshotsへ別recordとして確定する。cloud競合はremote documentをlocal recordのconflictへ保持する。「競合を別projectとして保持」は現在の案を新IDへforkし、元projectやremoteを変更しない。端末のproject一覧から開ける。ログイン済みSDKのcached ownerが得られるoffline時はlocal編集のみ可能（developer membershipの代用にはせずserverは毎回認可）。owner不明時は他人のlocal文書を推測して開かない。

cloudのrevisionはローカルrevisionと独立。online/定期同期がoutboxを処理し、失敗なら残す。先に送った古いrevisionのackは、さらに新しい編集のoutboxを消さずexpected cloud revisionだけを進める。同一案の再送は安定Idempotency-Key。同owner/sessionの取り違えはX-Project-OwnerとJWT ownerの比較でも拒否。新旧accountのprojectを無断で同期しない。local/cloudの保存状態を別表示し、ローカル保存だけでcloud保存済みとしない。

## API / DB

V1のJWT署名/issuer/audience/expiry、developer membership、owner照合、明示origin CORSを使用。user metadataによる昇格なし。service role/DB/R2 secret/font処理はserverのみ。PNG APIもmembershipを生成前後に再確認する。

| API                         | 内容                                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------------------- |
| GET /projects/:id           | owner projectとcloud revision                                                                        |
| POST /projects/:id          | project JSON、Idempotency-Key、If-Match `"N"`。初回N=0。成功時revision+1                             |
| POST /projects/:id/render   | `{}`、If-Match revisionを実行snapshotに固定。V4 batch/job/予約/outbox/cover pinを同transactionで作成 |
| POST /projects/text-preview | `{project,index}`から固定fontの文字PNG（base64）・寸法/font hash/renderer/fontSize                   |

If-Matchなし428、不一致409、別owner404、developer失効403。conflictは現revisionと提案をcloud側でもappend-only履歴に保持し、無断上書きしない。owner+project advisory lockとtransactionで同時更新を直列化。render前にmaterial/coverをowner/version/hash/kind照合する。raw例外、名前、snapshot、秘密、signed URLをlogへ出さない。

`005_all_versions_projects.sql`はprivate schemaにhead/history/conflictとrender optionsのproject columnを追加するreview用SQL。全project tableはowner必須/RLS/FORCE、履歴/競合は不変trigger、FK RESTRICT、DELETE権限なし。起動migration/down migrationなし。ローカル専用test DB以外に適用しない。

## 配布とrollback

server依存にMIT `@napi-rs/canvas` 1.1.0だけ追加、AleoはOFL1.1を同梱。browser直接依存のversionは変更なし。fontは`VIDEO_ALEO_FONT`で配置pathを指定できるが、内容hashは変更不可。Dockerfileはfont/licenseとnative runtime依存を配布対象へ含める。fontをNEXT_PUBLIC secretへ置かず、外部font serviceへruntime接続しない。

rollbackは`NEXT_PUBLIC_ALL_VERSIONS_ENABLED=false`で入口OFF。受付停止/drainはV4の手順。local/cloud project、outbox、原本、render outputs/checkpoints、履歴を保持する。DB downgrade/削除、契約、cloud作成、本番migration、main push、merge、deployは行わない。

検証の実行範囲と未完了事項は [V5検証記録](v5-verification.md) を参照。
